## Notes / Conventions

- App lives under `apps/web/` (single Next.js app, App Router).
- Database access exclusively via Drizzle; no raw SQL in route handlers.
- Auth.js v5 with JWT strategy; sessions exposed via `auth()` server helper.
- Owner-token auth (`OWNER_API_TOKEN` in `.env.local`) for the `scripts/manage.ts` CLI — separate from user sessions.
- Web Push VAPID keys live in `.env.local` (`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`).
- Service worker registered from `apps/web/public/sw.js` (or generated by `next-pwa` equivalent).
- All env vars documented in `docs/ENV.md` (to be created by `backend` on first env addition).
- Deploy target: Vercel. Supabase connection string via Vercel env vars in prod.
